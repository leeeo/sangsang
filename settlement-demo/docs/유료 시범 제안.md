# 주문 엑셀 정리·예상 정산표 자동화

> 게시 전 검토용 제안 초안입니다. 판매 등록·고객 발송·결제는 하지 않았습니다. 가격과 일정은 고객 반응을 확인하기 위한 가설입니다.

## 누구를 위한 작업인가요?

매주 또는 매월 같은 형태의 주문 엑셀을 합치고, 취소 건을 빼고, 수수료와 배송비를 정리하는 소규모 판매자를 대상으로 합니다.

**쓰던 파일 하나를 기준으로 반복 작업 한 가지를 줄이는 것**이 목표입니다. 모든 쇼핑몰을 지원하는 통합 정산 서비스가 아닙니다.

## 유료 시범 제안

**제안가: 150,000원**

- 합의한 입력 양식 **1종**
- 최대 5개 파일 병합, 합계 10,000행 범위
- 합의한 계산 규칙에 따른 정산 결과 XLSX **1종**
- 중복 주문·형식 오류 안내
- 짧은 사용 안내
- 합의한 범위 안에서 수정 **1회**
- 익명 샘플 검토 및 범위 확정 후 **3영업일 납품 목표**

파일 확인 전 확정 견적이 아닙니다. 최종 결제 금액, 세금·증빙 처리, 플랫폼 수수료, 일정은 계약 전에 확정합니다. 위 금액은 순수익이나 시장에서 검증된 판매 가격을 뜻하지 않습니다.

## 포함하지 않는 것

쇼핑몰 로그인·API 연동, 자동 수집, 여러 업체 양식 통합, 부분환불, 복수 상품 주문 재구성, 세무 신고, 실제 입금 대사, 24시간 운영, 무제한 유지보수는 포함하지 않습니다. 필요하면 별도 범위와 견적을 합의합니다.

현재 시제품의 표준 양식과 고객의 실제 파일이 다르면, 파일 확인 후 변환 규칙을 명시합니다. 아직 검증하지 않은 플랫폼 호환성을 약속하지 않습니다.

## 시작 전에 필요한 자료

1. 이름·전화번호·주소를 제거한 **가상 또는 익명 주문 20~50행**
2. 현재 수작업 결과 예시 1개
3. 완료·취소·할인·배송비·수수료를 처리하는 규칙
4. 작업 주기와 한 번 처리하는 대략적인 행 수
5. 이번 작업에 반드시 포함할 결과 항목

실제 고객의 개인정보나 쇼핑몰 로그인 정보를 요구하지 않습니다.

## 납품 확인 기준

고객과 미리 합의한 샘플의 수작업 결과와 자동 계산 결과가 일치해야 합니다. 중복·잘못된 입력은 파일명과 행으로 알려야 하며, 잘못된 일부 행만 제외한 결과를 정상인 것처럼 내보내지 않아야 합니다.

금액은 **예상 정산액**으로 표시합니다. 회계·세금·입금 보장을 하지 않습니다.

## 문의 답장 초안

안녕하세요. 반복해서 정리하시는 주문 엑셀을 한 가지 양식에 맞춰 자동화하는 시범 작업을 준비하고 있습니다.

개인정보를 지운 예시 파일과 지금 수작업으로 만든 결과를 보여주시면, 자동화 가능한 범위부터 확인하겠습니다. 제안 범위는 입력 양식 1종, 정산 결과 파일 1종, 수정 1회이고 제안가는 15만 원입니다. 파일을 확인한 뒤 최종 범위와 금액을 먼저 합의하며, 확인 전에는 결제를 요청하지 않습니다.
